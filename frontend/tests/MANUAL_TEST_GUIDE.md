# 前端手动测试指南

## 测试前准备

### 1. 启动服务
```bash
# 终端1: 启动后端
cd backend
npm run dev

# 终端2: 启动前端
cd frontend
npm run dev
```

### 2. 准备测试数据
- 创建一个测试考试（包含10-15题）
- 题目类型混合：选择题和判断题
- 设置30分钟时间限制

### 3. 测试浏览器
- [ ] Chrome（最新版本）
- [ ] Safari（Mac/iOS）
- [ ] Firefox
- [ ] Chrome Mobile（Android）
- [ ] Safari Mobile（iOS）
